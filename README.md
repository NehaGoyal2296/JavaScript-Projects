## Explore Canada — One-Page Website Lightbox

- `One-Page Website/one_page_website.html`: travel content, gallery and lightbox dialog.
- `One-Page Website/JS/one_page_website.js`: vanilla JavaScript lightbox controls.

Select either gallery image to open the lightbox. Previous and Next wrap through both images. Close, an outside click, or Escape dismisses it; Left/Right arrow keys navigate. Thumbnails can also be opened with Enter or Space. The original external Unsplash images and YouTube video require an internet connection.

Download or clone the repository and open `One-Page Website/one_page_website.html` in a modern browser to try the project.
