## One-Page Website Lightbox

[Explore Canada](One-Page%20Website/one_page_website.html) preserves the original HTML/CSS website and adds a plain JavaScript image lightbox. Click either thumbnail to view a larger image; use Previous and Next to browse, and Close, an outside click, or Escape to exit. Left/Right arrow keys also navigate.

To test, download or clone this repository and open `One-Page Website/one_page_website.html` in a modern browser. Test both images and each control. The original Unsplash images and YouTube video require an internet connection.
