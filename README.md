## Explore Canada — One-Page Website Lightbox

- One-Page Website/one_page_website.html: travel content, gallery and lightbox dialog.
- One-Page Website/JS/one_page_website.js: vanilla JavaScript lightbox controls.

Select either gallery image to open it. Previous and Next wrap through the images. Close, an outside click or Escape dismisses the lightbox; Left/Right arrow keys navigate. Enter or Space opens a focused thumbnail. External Unsplash images and YouTube video need internet access.

To preview, serve the repository root with a static web server and open /portfolio/ or /One-Page%20Website/one_page_website.html.
